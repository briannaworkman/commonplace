# Linked Thought

The value of a note collection is not in the notes; it is in the links between them. An unlinked
note is a dead end you will never find again. A linked note is reachable from every neighbour it
touches, and it becomes more reachable each time something is added nearby.

## Why linking compounds and filing doesn't

A folder hierarchy forces one location per idea, and every idea worth keeping belongs in several
places at once. Each new item in a folder tree therefore makes the tree slightly worse: more to
scan, more ambiguity about where a thing "should" live, no new paths to anything.

A linked collection behaves in the opposite way. Adding a note adds edges as well as a node, so
existing material becomes easier to reach, not harder. This is the compounding property that
makes a graph worth maintaining, and the concrete answer to the test posed in
[[The Collector's Fallacy]] — whether a system improves or degrades with size.

## Links as discovery, not just retrieval

Connection does more than help you find things again. Putting two ideas next to each other
produces combinations that neither contained on its own, which is why the [[Zettelkasten]]
tradition has been used as a creativity tool rather than merely a filing method. Luhmann treated
his slipbox as a conversation partner for this reason: it surfaced adjacencies he had not
remembered making.

Linking only works if the endpoints are specific, which is the requirement that
[[Atomic Notes]] exists to satisfy. Vague notes produce vague edges, and a graph of vague edges
tells you nothing.

## The same claim, made about work

The argument generalizes past note-taking. [[Graph Engineering]] makes an identical case
about how work is scheduled: a sequential plan imposes one ordering on steps that mostly
have no ordering between them, exactly as a folder tree imposes one location on ideas that
belong in several. Its "fake-edge test" — does step B actually consume step A's output? —
is the same question as asking whether a folder boundary reflects anything real.

That two sources this far apart, a Wikipedia page about index cards and an essay about
agent orchestration, converge on one claim is itself the argument for keeping a linked
collection. Neither would have surfaced the other in a folder.
